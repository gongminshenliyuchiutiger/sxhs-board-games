文化緣起：走進台灣人的靈魂廚房 Introduction

夜市，是台灣最富生命力、最具國際辨識度的常民文化縮影。煙霧蒸騰的鐵板、油鍋裡滋滋作響的酥脆炸物、人聲鼎沸的叫賣、濃郁撲鼻的藥膳香氣——這裡不僅填飽了島嶼世代人民的肚皮，更承載著幾百年移民社會融合的原味記憶。

《夜市人蔘》（Yes! Ginseng）將台灣夜市熱鬧非凡的「擺攤做生意」搬上牌桌！玩家扮演夜市攤位老闆，搶奪新鮮食材、烹調出令饕客垂涎的代表性道地小吃，更要面對同行惡意競爭、奧客挑釁、衛生稽查與警察開單的意外挑戰。每張餐點卡貼心標註了台語羅馬拼音（Taiwanese Romanization）與英文介紹，是向世界傳遞台灣飲食文化的絕佳教材！

經典 26 道台灣夜市名菜圖鑑 The 26 Delicacies

每張餐點卡皆標註售價（分數）、食材配方與文化淵源：

1. 蚵仔煎 (Ô-á-tsian / Oyster Omelet)

售價： 4 元 | 配方： 海鮮 x1 + 蔬菜 x1 + 雜糧 x1 + 高湯 x1

文化故事： 相傳明末鄭成功軍隊糧食短缺，以地瓜粉加水煎熟海邊採集的鮮蚵與野菜裹腹，流傳至今成為台灣夜市第一名物。

2. 滷肉飯 (Lóo-bah-pn̄g / Braised Pork Rice)

售價： 3 元 | 配方： 肉類 x1 + 雜糧 x1 + 高湯 x1

文化故事： 台灣國飯！以五花肉細切慢燉紅蔥頭與醬油，鹹甜膠質澆在熱騰騰米飯上，庶民經濟最踏實的幸福滋味。

3. 炸雞排 (Kue-phai / Giant Fried Chicken Cutlet)

售價： 3 元 | 配方： 肉類 x1 + 雜糧 x1 + 蔬菜 x1

文化故事： 比臉還大的外皮酥脆、肉汁噴發雞排，搭配九層塔提香，90年代起風靡全台成為宵夜霸主。

4. 臭豆腐 (Tshàu-tāu-hū / Deep-Fried Stinky Tofu)

售價： 2 元 | 配方： 雜糧 x1 + 蔬菜 x1

文化故事： 聞之欲嘔、入口銷魂！發酵豆腐外酥內嫩，塞入特調蒜蓉醬油與爽脆台式台泡菜，越臭越有味道。

5. 珍珠奶茶 (Tsin-tsu Leng-tê / Bubble Milk Tea)

售價： 2 元 | 配方： 雜糧 x1 + 高湯 x1

文化故事： 台灣揚名全球的軟實力代名詞！Q彈樹薯粉圓配上香濃奶茶，席捲歐美日韓。

6. 大腸包小腸 (Tuā-tn̂g Pau Sió-tn̂g / Sausage in Rice Sausage)

售價： 3 元 | 配方： 肉類 x1 + 雜糧 x1 + 蔬菜 x1

文化故事： 台式中式熱狗！以切開的糯米大腸夾入炭烤香腸，輔以蒜片、酸菜與花生粉，層次豐富無窮。

7. 鹽酥雞 (Iâm-soo-ke / Taiwanese Popcorn Chicken)

售價： 2 元 | 配方： 肉類 x1 + 雜糧 x1

文化故事： 獨門中藥醃製雞丁裹粉高溫酥炸，灑上濃郁胡椒鹽與蒜頭九層塔，最具社交氛圍的下酒小菜。

8. 小籠包 (Sió-lông-pau / Steamed Soup Dumplings)

售價： 3 元 | 配方： 肉類 x1 + 雜糧 x1 + 高湯 x1

文化故事： 皮薄如紙十八折，咬開瞬間鮮甜肉汁溢滿湯匙，名揚國際的精緻麵食工藝。

9. 筒仔米糕 (Tâng-á-bí-ko / Tube Rice Pudding)

售價： 2 元 | 配方： 雜糧 x1 + 肉類 x1

文化故事： 盛裝於特製鐵筒中蒸透的油飯，倒扣盛盤後淋上濃稠甜辣醬，散發香菇蝦米濃醇香氣。

10. 豬血糕 (Ti-hueh-ko / Pig's Blood Cake)

售價： 1 元 | 配方： 雜糧 x1 + 蔬菜 x1

文化故事： 曾獲外媒評為「全球十大最怪美食」，但台灣人蒸透後沾滿花生粉與香菜插竹籤吃，美味無比。

11. 棺材板 (Kuan-tshâ-pang / Coffin Bread Toast)

售價： 3 元 | 配方： 雜糧 x1 + 肉類 x1 + 高湯 x1

文化故事： 台南沙卡里巴代表點心，厚片土司油炸至金黃酥脆，挖空內部舀入海鮮雞肉濃湯，取名寓意「升官發財」。

12. 蚵仔麵線 (Ô-á Mī-suànn / Oyster Vermicelli)

售價： 3 元 | 配方： 海鮮 x1 + 雜糧 x1 + 高湯 x1

文化故事： 柴魚高湯勾芡紅麵線，鋪上肥美生蚵與滷透大腸，淋上黑醋、蒜泥與特製辣油，站著吃也過癮。

13. 牛肉麵 (Gû-bah-mī / Taiwanese Beef Noodles)

售價： 4 元 | 配方： 肉類 x1 + 雜糧 x1 + 高湯 x1 + 蔬菜 x1

文化故事： 戰後眷村老兵將四川辣豆瓣醬與台灣黃牛肉慢火熬燉結合，淬煉出享譽海內外的紅燒極致。

14. 芒果冰 (Bāng-kó-ping / Mango Shaved Ice)

售價： 2 元 | 配方： 雜糧 x1 + 蔬菜 x1 (鮮果)

文化故事： 盛夏台灣必吃！細緻綿密雪花冰堆滿愛文芒果切丁，淋上香濃煉乳與一球芒果冰淇淋。

15. 藥膳排骨 (Io̍h-siān Pâi-kut / Herbal Rib Soup)

售價： 3 元 | 配方： 肉類 x1 + 高湯 x1

文化故事： 熟地、當歸、枸杞等數十種珍貴中藥材慢火熬燉豬肋排，夜市溫補元氣的第一首選。

16. 生魚片 (Chha-mi / Sashimi)

售價： 1 元 | 配方： 海鮮 x1

文化故事： 港都漁市直送現切，厚切旗魚、鮭魚與鮪魚沾上現磨山葵，日治飲食習慣融入夜市的活證。

17. 蝦仁飯 (Hê-jîn-pn̄g / Shrimp Rice)

售價： 2 元 | 配方： 海鮮 x1 + 雜糧 x1

文化故事： 火燒蝦快炒蔥段與高湯，拌入蒸煮入味的米飯中，鮮味透澈的府城古早味。

18. 胡椒餅 (Hôo-tsio-piánn / Taiwanese Pepper Bun)

售價： 2 元 | 配方： 肉類 x1 + 雜糧 x1

文化故事： 福州蔥肉餅改良，貼在高溫炭火陶缸壁烘烤，外皮焦香酥脆，內餡黑胡椒豬肉汁滾燙誘人。

19. 蔥抓餅 (Tshang-jiok-piánn / Flaky Scallion Pancake)

售價： 2 元 | 配方： 雜糧 x1 + 蔬菜 x1

文化故事： 麵糰層層抹油揉入鮮蔥，鐵板拍打出蓬鬆多層次的酥脆口感，加蛋加起司更是絕配。

20. 地瓜球 (Tsi-tsiam-kiû / Sweet Potato Balls)

售價： 1 元 | 配方： 雜糧 x1

文化故事： 又稱QQ蛋，油炸時師傅不斷拿大勺下壓擠出空氣，膨脹成金黃圓滾、外脆內嚼勁的零嘴。

21. 滷味拼盤 (Lóo-bī / Braised Snacks)

售價： 2 元 | 配方： 蔬菜 x1 + 雜糧 x1

文化故事： 熱騰騰的老滷湯汆燙黑豆干、海帶與時蔬，隨心夾選、豐儉由人，夜市最貼心的宵夜好伴侶。

22. 潤餅 (Jūn-piánn / Taiwanese Spring Roll)

售價： 2 元 | 配方： 雜糧 x1 + 蔬菜 x1

文化故事： 薄潤餅皮包捲高麗菜、豆干、紅糟肉、香菜與厚厚一層花生糖粉，尾牙與清明傳承數百年美味。

23. 刈包 (Kuah-pau / Pork Belly Bun)

售價： 2 元 | 配方： 肉類 x1 + 雜糧 x1

文化故事： 鬆軟白麵餅夾入肥美三層肉，被戲稱為「虎咬豬」，象徵將壞運咬掉、帶來財富。

24. 擔仔麵 (Tànn-á-mī / Slack Season Noodles)

售價： 3 元 | 配方： 雜糧 x1 + 海鮮 x1 + 高湯 x1

文化故事： 台南漁民在颱風「小月」期間挑擔沿街賣麵貼補家用，肉燥加上一尾鮮蝦，成就百年老字號。

25. 鼎邊趖 (Tiann-pinn-sô / Ding Bian Cuo)

售價： 3 元 | 配方： 雜糧 x1 + 海鮮 x1 + 高湯 x1

文化故事： 基隆廟口必吃！在鐵鍋鼎邊將在來米漿滑動烙成米皮，煮入鮮蚵肉羹湯中，滑嫩鮮美。

26. 仙草冰 (Sian-tsháu-ping / Grass Jelly Ice)

售價： 1 元 | 配方： 高湯/甜湯 x1

文化故事： 古法熬煮仙草乾凝結成果凍般的黑色仙草凍，消暑降火，台灣土地最純淨的清涼餽贈。

遊戲準備 Setup

  1. 分類牌堆： 將「食材牌」、「餐點牌」與「功效牌」三大牌堆各自洗勻，牌面朝下置於中央。
  2. 翻開餐點訂單： 從餐點牌堆翻開 3 張餐點牌 排列在場上，作為全場夜市攤位共同搶做的料理訂單。
  3. 發放起始手牌： 每位玩家從食材牌庫抽取 5 張食材牌 作為起始手牌。
  4. 準備銀行庫存： 將 60 元硬幣置於一旁形成銀行金庫。任選一位玩家作為起始玩家，按順時針進行。

遊戲進行：擺攤做生意流程 Gameplay

輪到你的回合時，依序執行下列四大階段：

  1. 階段一：進貨補菜 (Draw Ingredients)

    回合一開始，直接從食材牌堆頂免費抽取 3 張食材牌加入手牌（無論手上原本有幾張）。

  2. 階段二：料理出菜 (Cook & Earn)

    檢視手牌與場上的 3 張餐點牌：

    • 只要手牌中的食材符合某張餐點牌的需求，即可打出該組食材卡放入棄牌堆，並拿走該張餐點牌置於自己面前！
    • 領取收益： 立即從銀行拿取該餐點牌上標註的金額（例如蚵仔煎拿 4 元、滷肉飯拿 3 元）。
    • 即時補牌： 拿走餐點牌後，立刻從餐點牌庫翻開 1 張新牌補足 3 張。
    • 不限出菜次數： 本回合只要手牌足夠，你想做幾道菜就做幾道菜，盡情大展身手！

  3. 階段三：同行鬥爭與購買道具 (Buy & Play Special Cards)

    • 購買功效牌： 你可以花費 2 元現金，向銀行購買 1 張功效牌加入手牌（單回合不限購買張數）。
    • 使用功效牌： 你可以打出手上的攻擊、輔助、替換類功效牌陷害競爭對手或強化自身產能（不限次數）。防禦牌則在受到他人攻擊時即時出示抵擋。

  4. 階段四：收攤與手牌上限檢查 (End Turn & Discard)

    回合即將結束時，檢查手牌總數（食材牌 + 功效牌）：

    • 手牌上限為 8 張！ 若超過 8 張，必須自行選擇丟棄多餘的牌至棄牌堆，直到手牌剩下剛好 8 張為止。
    • 宣告收攤，由順時針下一位攤主接續營業。

攻防功效牌詳細說明 Special Action Cards

防 衛生稽查 (Hygiene Inspection)

震撼彈！所有防禦牌無效！ 全場所有玩家（包括發動者自己）必須立即丟棄手上所有的食材牌放回棄牌堆！專門用來同歸於盡、破壞即將胡牌的對手。

攻 食物中毒 (Food Poisoning)

向指定對手索賠醫藥費 1 元，並高喊 1 種食材名稱（如「海鮮」），該對手手上所有該種食材必須全數丟棄！

攻 警察取締 (Police)

檢舉路邊攤違規設攤！被檢舉者必須在「繳納罰款 2 元給銀行」或「丟棄手上所有食材」兩者中二選一。

攻 蟑螂出沒 (Cockroach)

丟向對手攤位！該玩家下一個回合被強制暫停營業做菜一回合，但仍可抽 3 張食材或購買功效牌。

攻 奧客光臨 (Picky Customer)

由你隨機抽走並丟棄該玩家手上一半數量的食材牌（無條件進位），狠狠整肅對手儲備。

攻 扒手現身 (Pickpocket)

神不知鬼不覺，直接從指定對手錢包中偷走 2 元現金。

攻 偷菜賊 (Card Pilferer)

從指定對手手上硬生生奪取 2 張食材牌加入自己手牌。

輔 上電視 (Media Exposure)

美食節目採訪宣傳！立即從食材牌庫額外抽 3 張食材牌，生意興隆。

輔 買菜抓把蔥 (Greedy)

翻開食材庫頂牌，若是青菜（含爛菜）可連帶額外多抽 2 張食材牌！

防 黑社會罩 (Gangster)

地頭蛇保護！當你遭受攻擊時打出，直接將該攻擊效果原封不動反彈回攻擊者本人自食惡果！

防 夜市之光 (Market Idol)

五星良心優良攤商獎狀！可抵擋除了「衛生稽查」之外的一切攻擊陷害！

換 佛跳牆 (Monk Jumps Over The Wall)

雙手合十朗誦「阿彌陀佛」！本回合內你可不限次數以「肉或五穀雜糧」任意替代「肉或海鮮」。

輔 YES! WE SPEAK ENGLISH

雙語友善攤商！可在場上橫向額外翻開第 4 張餐點牌搶先製作，擴大接單優勢。

勝負結算與廚神判定 End Game & Scoring

當餐點牌堆全數被搶做完畢（或場上已無卡牌可補）時，遊戲正式結束！

  1. 餐點數量冠軍： 結算每位玩家面前累積的「餐點牌總數量」，數量最多者榮獲「夜市食神」桂冠！
  2. 金額平手比序： 若完成的餐點張數相同，則加總手中賺得的硬幣現金總額，金額高者獲勝！若依舊相同則共享榮譽。

社會科深入思辨：夜市常民經濟與都市治理

新北市立雙溪高級中學《從桌遊看社會》專題探討：小吃攤販是都市毒瘤還是文化瑰寶？

思辨一：非正式經濟（Informal Economy）與社會安全網（經濟學／社會學）

Q1：為什麼夜市小吃攤販在台灣歷經數十年依然生生不息？它扮演了什麼經濟角色？
在社會學與經濟學中，夜市屬於典型的「非正式經濟（Informal Economy）」。它具有「微型創業門檻低、資金週轉快、技術親民」的特色，在台灣多次經濟轉型與金融風暴中，收納了許多失業勞工與中高齡轉業者，成為維繫底層家庭生計的「社會安全閥」。同時，夜市將利潤留在在地平民手中，創造了蓬勃的微型就業生態。

思辨二：食安監管與常民美味的兩難（公共行政與法治）

Q2：遊戲中的「衛生稽查」讓全場丟牌，反映了現實中夜市面臨什麼制度挑戰？
街頭小吃往往缺乏中央廚房規格的溫控設備與溯源管理，從過去的餿水油風暴、塑化劑到蘇丹紅辣椒粉事件，食品安全往往是夜市最大的軟肋。政府若以高標準嚴加查緝與重罰，恐迫使大批小本經營的小販倒閉；但若放任不管，又置公眾健康於險境。現代都市治理正透過「食安登錄碼（溯源QR code）」、集中油脂截流槽與從業人員衛生講習，在美味與安全間取得平衡。

思辨三：文化資產、米其林必比登與在地仕紳化（文化人類學）

Q3：當夜市小吃獲得米其林推薦後，對在地居民的生活帶來了哪些利與弊？
文化觀光行銷帶來了龐大的國際觀光客與外匯收入，提升台灣飲食的國際能見度；然而，這往往伴隨著嚴重的「仕紳化（Gentrification）」與鄰避效應：店租大幅飆漲排擠在地老攤商、排隊人潮阻塞交通、油煙與噪音破壞社區安寧、餐點價格水漲船高，最終讓原本服務在地鄰里常民生活的夜市，變質為純粹討好遊客的高價觀光樣板。
